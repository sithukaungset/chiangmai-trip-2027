Public trip plan page for Dad & Son — **ချင်းမိုင် · Apr 14 arrive – Apr 17 depart, 2027**.

Burmese guide covering Old City hotels, nearby golf courses (KRW / USD estimates), Songkran notes, map, and day-by-day plan.

## Open locally

Open `index.html` in a browser, or serve the folder:

```bash
npx --yes serve .
```

Then visit the URL printed in the terminal (usually `http://localhost:3000`).
